# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- **The external driver (`mcp-external-driver`).** Runs whose runtime is `n8n_workflow`,
  `fr_project` or `fr_command` are now driven by a Rust process instead of the archived Python
  one. It is the single writer of those runs: an at-most-once dispatch (the `dispatch` event is
  committed before the upstream call, and a run found `starting` with that event and no external
  reference is `interrupted`, never re-sent), a lease kept alive across a slow upstream answer,
  deadline and cancel handling through `cancelling`, one-shot `fr_command` answers replayed from
  the stored reference, and forwarding of answered task inputs back to fr.
- The n8n adapter (webhook start with a two-minute HS256 JWT, execution polling with a 4 MiB body
  cap, result extraction with a 64 KiB cap, an `unknown`-status counter) and the fr adapters (an
  HMAC-signed channel envelope, project start/poll/cancel, `projects.get`/`projects.close`, and a
  bounded project view).
- `tests/fixtures/phase3c/oracle.json`, generated by the pinned Python reference itself
  (`parity/tools/gen_phase3c_fixtures.py`), so every signature, JWT, channel envelope and bounded
  view is compared against the reference rather than an assumption.

## [0.1.0] - 2026-11-14

First public release: the health surface and the MCP handshake, ported from the reference
implementation and verified against its OpenAPI document.

### Added

- Health endpoints `GET /health`, `/health/live`, `/health/ready` and `/api/health`, matching
  the reference implementation's responses.
- An MCP endpoint at `/mcp` over the streamable HTTP transport. `initialize` negotiates the
  protocol version; `tools/list` returns an empty catalog. The wire shape is stateless and
  SSE-framed, and `capabilities.tools.listChanged` is serialised as an explicit `false`, as the
  reference does.
- PostgreSQL pool and embedded migrations, with `DATABASE_MIGRATE_URL` for running migrations
  around a transaction-pooling connection pooler.
- OpenAPI document generation (`--print-openapi`) that reads no configuration and touches no
  database, so parity tooling can diff it in a bare workspace.
- The parity contract (`parity.toml`) pins the reference implementation and names, phase by
  phase, every operation that is not yet ported.

### Not yet

- The tool catalog, credential broker and execution worker. See the README's table.
